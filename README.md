# 🌊 WAVE DEFENDER | GRID STRATEGY

![Status](https://img.shields.io/badge/Status-Beta-purple)
![Version](https://img.shields.io/badge/Version-8.5.1-cyan)

**Wave Defender** is a premium neon-noire grid strategy game. Build, survive, and synergize structures to defend your base against a relentless host of anomalies.

## 🚀 Features
- **Dynamic Grid Combat**: Position troops and towers in a tactical grid.
- **Deep Synergy System**: 20+ unique combos and visual connections.
- **Protocol Omega**: High-stakes legendary events that trigger after Wave 20.
- **Soul Forge**: Meta-progression system to boost your stats between runs.
- **Codex & Bestiary**: Catalog of 30+ enemies and structures.

## 🛠️ Technology Stack
- **Core**: Vanilla JavaScript (ES6+)
- **Styling**: Modern CSS (Custom Properties, Flexbox, Grid)
- **VFX**: Canvas-based synergy lines and CSS Keyframe animations.
- **Persistence**: LocalStorage with auto-save.

## 🕹️ How to Play
1.  **Preparation**: On Wave 1, pick your starting troop.
2.  **Building**: Buy structures from the market and place them on the grid.
3.  **Synergy**: Place complementary towers side-by-side to activate visual combos.
4.  **Survival**: Survive waves to earn Coins and Souls. Use Souls in the Soul Forge to get permanent upgrades.
